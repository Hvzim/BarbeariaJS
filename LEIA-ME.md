# Estilo Livre — atividade Bootstrap

Projeto de página institucional fictícia para a atividade de Bootstrap da EBAC.

## Arquivos
- `index.html`: navbar responsiva, banner, sobre, serviços, depoimentos em carousel e formulário.
- `css/style.css`: estilos complementares e ajustes responsivos.
- `js/scripts.js`: fecha o menu mobile ao selecionar um link e valida o formulário.
- `img/`: ilustrações SVG locais usadas pelo site.

## Como executar
Abra `index.html` com o VS Code Live Server. Bootstrap 5.3.3 é carregado por CDN, então é necessária conexão com a internet para os componentes Bootstrap.

## Observação sobre o formulário
O formulário é demonstrativo: valida os campos no navegador, exibe uma confirmação e registra os dados no console, mas não envia e-mail nem grava os dados em um servidor.
